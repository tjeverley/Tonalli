# Tonalli
Third Person Puzzle Platformer with themes of Central American Mythology

Current Mechanics Implemented:
- Pick up items
- Healing (health items added)
- Sprinting
- Stamina reduction & restoration (fixed)
- Multi-lock gates (upgraded to 3 keys; 4 key variant)
- Capstan ratchet/hoist system
- Glyph puzzle (4 and 8 glyph variants)
- Pick up gears/cogs
- Gear/Cog Wall Puzzle
- Game Pad Compatibility
- Spike Traps
- Dart traps
- Basic UI/HUD
- Pause
- Save/Load (Autosave added; opened doors tracked)
- Custom Player model & animations
- Custom Enemy models and animations
- Enemy AI
- Combat mechanics (mostly complete)
- Messages/Dialogue system
- Upgrade System
- Tutorial System
- Rotation/Ring Puzle
- Bridge Puzzle
